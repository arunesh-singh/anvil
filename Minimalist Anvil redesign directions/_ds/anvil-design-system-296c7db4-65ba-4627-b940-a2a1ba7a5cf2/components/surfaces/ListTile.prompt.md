Row for any scrolling list — history records, output files, settings groups.

```jsx
<ListTile leadingIcon="call_split" title="Split PDF" subtitle={"report.pdf\n2026-08-04 14:02"} lines={3} onClick={open} />
```

Title is body-large on-surface; subtitle body-medium on-surface-variant. Trailing holds `IconButton`s, never text buttons.
