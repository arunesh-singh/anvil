PDF tools — one workspace

Left: the editors as they ship today, recreated from lib/ui/tool/editors/. Right: two ways to collapse eight tool-per-screen editors into one document workspace.

Today

A screen per tool

Each op is its own route: pick a file, set params blind, Run, get a result. Nothing carries between them.

Direction A

Document + op bar

The page grid is the home. Ops are sheets over it, edits stack up and are undoable, one Export at the end.

Direction B

Preview first

The rendered page is the screen. Every parameter redraws it live, with the output size beside the control.
